# VLS vanilla — 후보 재순위, 채점 함수는 VLM 이 자연어 조문에서 쓴다

원리(`../paper.pdf`): 정책이 낸 **후보 행동 여러 개**를 보상으로 재순위한다. vanilla 에서는 그 보상을
**gemini-flash** 가 법 조문(자연어)과 특권 상태를 읽고 **파이썬 채점 함수**로 쓴다. 정책 가중치는 손대지 않는다.

## VLM 이 내야 하는 것

```python
def score(priv, action) -> float:
    """priv: /priv 응답(dict). action: {"vx": -0.6|0|1.2, "wz": [-1,1], "beacon": bool}"""
```
- 프롬프트: 법역 조문 요약 + 태스크 + `/priv` 예시 + "진행(목표 방향으로 vx>0)은 보상, 이 법이 지금 금지하는 것
  (신호 아닌데 진입, 차도 역주행, 통행폭 미달, 보행자 근접, 도색 위 정지, 금지된 차도 주행, 차도에서 점멸등 꺼짐)은 큰 벌점".
- `exec` 는 제한 builtins(`abs,min,max,float,int,len,round,any,all,sum,sorted,…`)와 `math` 만 준 네임스페이스에서.
- **컴파일만 믿지 말고 실행 검증**: 대표 `priv` 로 한 번 호출해 예외가 없어야 채택. 실패하면 이전 함수를 유지.
- `max_tokens ≥ 2500`(추론 토큰에 잘린다). 에피소드 시작 때 동기로 1회, 이후 20 s 마다 비동기 갱신. 예산 30회.

## 후보

정책 서버에 `n=1, temperature=0`(탐욕) + `n=3, temperature=0.8`(샘플) → 최대 4개 행동 × `beacon∈{off,on}` = 8 후보.
텍스트 정책이라 후보 수가 곧 지연이다(호출당 ~1.6 s) — 결정 주기를 1.5 s 로 둔다.

## 선택

`argmax_c score(priv, c)`. 함수가 없거나 전부 예외면 탐욕 후보. 선택된 후보의 점수와 후보 수를 `note` 에 남긴다.

## 기대되는 것

- 정책 후보가 전부 위반(예: 4개 모두 `vx=1.2` 로 적색 진입)이면 **재순위로는 못 막는다** — 이것이 SC 와의 구조적 차이고
  표에 드러나야 할 점이다. 샘플 온도를 올려 다양성을 확보하는 것이 유일한 여지다.
- `beacon` 후보가 있어 EE T2 는 준수 가능.
