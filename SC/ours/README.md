# SC + ours — 안전 제약 필터, 제약은 법별 **미분 가능한 장벽 함수**로 손으로 쓴다

vanilla 와 필터 자리는 같다. 다른 것은 **안전 집합이 어디서 오는가**다. VLM 이 매 에피소드 자연어를 읽고 JSON 을
쓰는 대신, **법역마다 장벽 함수 `h_law(x, a)` 를 코드로 한 번** 쓴다. 특권 상태로 **장면 그래프**를 만들고, 그 위에서
장벽을 계산하며, `∇_a h` 를 autograd 로 얻어 행동을 안전 집합 안으로 투영한다. 실행 중 VLM 호출은 **0회**다.

프랑카 벤치마크의 `common/scene_graph.py` + `common/diffreward.py`(안전항 h·∇h 를 CBF 장벽으로) 와 같은 구조를
도시 주행으로 옮긴 것이다.

## 1. 장면 그래프 (`/priv` → torch 텐서)

```
robot:      p=(x,y), yaw, v, beacon
surface:    kind ∈ {sidewalk, roadway, shared, off}, corridor {axis, lo, hi} (통로 경계), free width
crosswalk:  center, axis, half_len=5.5, half_dep=2.0, on
signal:     ped ∈ {grn,cnt,off,red}, green_remaining, need_s, can_finish
peds:       [(px,py,vx,vy,slow)] 로봇 기준 15 m 안
goal:       (gx,gy)
```
모든 기하는 `Geo` 와 같은 수치를 쓴다(통로 경계·도색 사각형·연석). 장벽이 채점기와 **같은 것**을 재야
"준수했는데 위반"이 안 난다.

## 2. 행동 모델

`a=(vx, wz)` 에 대해 **짧은 지평 운동학**을 미분 가능하게 편다: `dt=0.1`, `H=15`(1.5 s),
`x_{k+1}=x_k+vx cos ψ_k dt, y_{k+1}=…, ψ_{k+1}=ψ_k+wz dt`. 장벽은 예측 궤적 전체의 최소값
`h(a)=min_k h(x_k)` (soft-min, β=0.05) 로 둔다. 로봇 반폭 0.305, 보행자 반폭 0.32.

## 3. 법별 장벽 (h ≥ 0 이 안전)

| | GA | OH | EE |
|---|---|---|---|
| **보도 통행폭** | `h₁ = free(x_k) − 1.219` — `free` 는 통로 경계와 로봇·장애물 간 거리에서 미분 가능하게(부호 거리) | 없음 | 없음(판정불가) |
| **보행자** | `h₂ = d_ped − (0.305+0.32+0.6)` (접촉 반경 0.74 + 여유) | 같음 | `h₂ = d_lat − 0.63`(앞지르기) + 접근 감속 `h₂' = 1.34 − d` 일 때 `v ≤ 0.25` |
| **횡단 게이트** | 도색 가장자리 2 m 안·진입 방향일 때 `h₃ = 𝟙[ped=grn]·1 − 1` (게이트 닫힘 = −1) | 같음 | `h₃ = green_remaining − need_s` (녹색 아니면 −∞ 대신 −10) |
| **횡단 중** | `h₄ = v − 1.067`(하한) ∧ `1.788 − v` | `h₄ = right_half_margin` (도색 중심선 기준 부호 거리, 진행방향으로 회전) | `h₄ = v − 0.1`(정지 금지) |
| **차도** | `h₅ = right_margin` (도로 중심선 기준 우측이면 +) | `h₅ = −𝟙[kind=roadway ∧ ¬on_crosswalk]` — **차도에 있는 순간 음수**, 투영은 후진만 허용 | `h₅ = right_margin`, `h₆ = 𝟙[beacon] − 1` (차도에서 점멸등 꺼짐 = −1 → 이산 행동 `beacon=on`) |
| **공유공간** | 없음 | 없음 | 없음 |

이산 스위치(`beacon`, `kph`)는 장벽 값으로 결정한다: `h₆ < 0` 이면 `beacon=on`. `kph` 는 GA 횡단 하한을 위해 `0`(전속).

## 4. 투영 (CBF-QP 의 1스텝 근사)

정책 행동 `a₀` 에 대해
```
a* = argmin_a ‖a − a₀‖²   s.t.  h_i(a) + α·h_i(x_now) ≥ 0  ∀i        (α = 3.0)
```
를 **기울기 투영**으로 푼다: `a ← a₀`; 위반한 제약 i 마다 `a ← a + η·∇_a h_i / ‖∇_a h_i‖`(η=0.15, 최대 8회),
`vx` 는 `{-0.6, 0, 1.2}` 로 스냅, `wz` 는 [−1,1] 클립. `∇_a h_i = 0`(장벽이 행동과 무관 — 게이트류)이면 `vx=0` 으로.
장벽이 **안쪽에서도 부호 거리**여야 한다 — 상자 SDF 가 내부에서 0 이면 기울기가 죽어 보호가 필요한 순간 사라진다
(프랑카에서 겪었다).

## 5. 무엇이 vanilla 와 다른가 (표에서 보여줄 것)

- 실행 중 VLM 0회 → 결정 지연이 정책 지연뿐. `vlm_calls=0` 을 기록한다.
- 제약이 **연속값**이라 "얼마나 위험한가"에 비례해 민다(vanilla 는 임계에서 on/off).
- 법 해석 오류가 에피소드마다 재현되지 않는다(vanilla 는 VLM 이 매번 다르게 읽을 수 있다).
- 같은 `h` 가 VLS+ours 의 보상 안전항으로 재사용된다.

## 6. 검증 순서

1. 스텁 정책(항상 `[1.2, 0]`)으로 T4 에서 게이트가 닫히고 녹색에 열리는지, T2 에서 OH 가 후진·EE 가 점멸등을 켜는지.
2. 각 장벽을 채점기와 대조: 장벽이 ≥0 인데 채점기가 위반이면 기하 불일치 — 장벽 쪽을 채점기에 맞춘다.
3. 그 다음에야 VLA 위에 얹는다.
