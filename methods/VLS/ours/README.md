# VLS + ours — 보상 기울기 조향, 보상은 법별 **미분 가능한 코드**로 손으로 쓴다

vanilla 는 이산 후보를 채점해 고른다. ours 는 **연속 행동 공간에서 `∇_a R_law` 로 정책 행동을 민다.**
보상은 법역마다 코드로 한 번 쓰고(`methods/SC/ours` 의 장벽 `h` 를 안전항으로 재사용), 장면 그래프 위에서
autograd 로 미분한다. 실행 중 VLM 호출은 **0회**.

프랑카 벤치마크에서 `diffreward.py` 의 `R(p)` 를 디노이징에 주입하던 것과 같은 자리다. 다만 이 정책은
**텍스트로 행동을 내는 VLA** 라 잠재변수에 주입할 곳이 없다 — 그래서 **정책이 낸 행동을 시작점으로 행동에 대해
기울기 상승**을 한다(신뢰영역 안에서).

## 1. 보상 (행동 `a=(vx, wz)` 에 대해 미분 가능)

`methods/SC/ours` 의 운동학 롤아웃(1.5 s)을 그대로 쓴다.

```
R_law(a) = R_task(a) + R_safe_law(a)

R_task  = −‖p_H(a) − goal‖ + 0.3·cos(ψ_H − bearing_goal)              # 목표 접근·정렬
R_safe  = −Σ_i w_i · softplus(−h_i(a) / β)²                             # 법별 장벽 위반량 (β=0.05, w_i=20)
          + 2.0·𝟙[게이트 열림]·vx                                          # 녹색에서 머뭇거리지 않게 (T4)
```
`h_i` 는 `methods/SC/ours` §3 표 그대로(GA: 통행폭·접촉·게이트·횡단속도·차도우측 / OH: 접촉·게이트·우측절반·차도금지 /
EE: 양보·완주게이트·정지금지·우측·점멸등). 판정불가 조항은 항이 없다.

## 2. 조향

```
a ← a_VLA
for k in 1..K:                       # K=8
    g = ∇_a R_law(a)                 # autograd
    a ← a + λ · g / (‖g‖ + ε)        # λ=0.05
    a ← a_VLA + clip(a − a_VLA, −δ, δ)   # 신뢰영역 δ=(0.6, 0.35)  — 정책에서 너무 멀어지면 매니폴드를 벗어난다
vx ← snap{-0.6, 0, 1.2}, wz ← clip[-1,1]
beacon ← (h_beacon(a) < 0)           # 이산 스위치는 장벽으로
```
게이트류(`∇_a h=0`)는 기울기가 없으므로 **보상값 자체**로 처리한다: `R_safe(a_VLA) < −5` 이고 `vx>0` 이면 `vx=0`.

후보 재순위도 함께 쓴다(`n=1 탐욕 + n=3 샘플`): 각 후보에서 위 상승을 돌린 뒤 `R_law` 최대를 고른다.
그래야 vanilla 와 후보 수·지연이 같아 비교가 공정하다.

## 3. 무엇이 vanilla 와 다른가

- 후보가 전부 위반이어도 **행동을 옮겨** 준수 후보를 만든다(vanilla 는 있는 것 중에서만 고른다).
- 보상이 채점기와 같은 기하·임계값을 쓴다 → "보상 최대인데 위반" 이 나지 않는다(VLM 코드는 조문을 잘못 읽을 수 있다).
- 실행 중 VLM 0회.

## 4. 함정 (프랑카에서 겪은 것)

- 기울기 주입을 세게 하면 정책이 낸 행동과 멀어져 **정책 분포 밖**으로 나간다(프랑카 VLS_authentic 이 vanilla 보다 나빴던 이유).
  신뢰영역 δ 를 넘기지 말 것.
- 장벽 SDF 가 안쪽에서 0 이면 `∇=0` — 위험 안에 들어간 순간 밀어낼 방향을 잃는다. 부호 거리로 쓴다.
- 상수를 짐작하지 말 것 — 도색 반길이 5.5, 두께 반 2.0, 보도 폭 3.0, 접촉 반경 0.74 는 레이아웃·채점기 값이다.
