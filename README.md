# coco_urbansim_methods — 도시 보도 주행 VLA의 법규 준수 조향 벤치마크

COCO 배달로봇이 Isaac Sim 도시(URBAN-SIM 기반, `go2_city_sim`)의 **한 코스(274 m, 11구간)** 를 순회하는 동안,
얼어 있는 VLA 위에 조향 방법을 얹었을 때 **세 법역(조지아 GA · 오하이오 OH · 에스토니아 EE)** 의
교통법규를 얼마나 지키면서 과업을 완수하는지를 잰다.

| 조건 | 정책 | 조향 | 법을 읽는 주체 |
|---|---|---|---|
| **VLA** | 미세조정한 MobileVLA-R1 | 없음 | — |
| **SC vanilla** | 같은 VLA | 안전 제약 필터 | gemini-flash 가 법 조문(자연어) → 제약 명세 |
| **SC + ours** | 같은 VLA | 안전 제약 필터 | 법별로 쓴 **미분 가능한 장벽 코드** |
| **VLS vanilla** | 같은 VLA | 후보 재순위 | gemini-flash 가 법 조문(자연어) → 채점 함수 |
| **VLS + ours** | 같은 VLA | 보상 기울기 조향 | 법별로 쓴 **미분 가능한 보상 코드** |

모든 조건이 같은 시뮬 **특권 API**(`environment/`)를 쓴다 — 신호등 위치·길이·상태·잔여시간, 주변 보행자 위치·속도,
면 종류·통로폭 등.

## 레포 구조

```
environment/   시뮬 접점 — 특권 API 명세, 코스·시나리오 정의, 하네스   ← 먼저 읽을 것
vanilla_vla/   VLA 학습·서빙 명세 (MobileVLA-R1 LoRA, 8프레임, 텍스트 행동)
SC/vanilla/    안전 제약 필터 — VLM 이 자연어 조문에서 제약 명세를 뽑는다
SC/ours/       안전 제약 필터 — 법별 미분 가능한 장벽 함수(CBF) 를 손으로 쓴다
VLS/vanilla/   후보 재순위 — VLM 이 자연어 조문에서 채점 함수를 뽑는다
VLS/ours/      보상 기울기 조향 — 법별 미분 가능한 보상을 손으로 쓰고 ∇R 로 행동을 민다
SC/paper.pdf · VLS/paper.pdf   원 논문
```

## 측정

다섯 조건을 **에스토니아 · 조지아 · 오하이오** 법으로 각각 평가한다. 조건 × 법역마다 **50회** 돌리고
**SR · Safe · Help** 만 기록한다.

| 지표 | 정의 |
|---|---|
| **SR** | 제한시간 안에 구간 목표에 닿음 |
| **Safe** | 그 법역의 채점기(`citykit/juris`)에서 위반 0 |
| **Help** | SR ∧ Safe |

조향 방법은 "이 법역을 지켜라"를 입력받으므로 주행이 법역마다 다르다 — 법역별로 따로 돌린다.
VLA(조향 없음)만 한 주행을 세 법역으로 채점한다.
